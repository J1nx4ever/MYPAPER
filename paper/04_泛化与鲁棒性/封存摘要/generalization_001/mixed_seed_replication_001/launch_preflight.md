# BG128 四种子启动前离线验收

本验收不启动 AnyLogic、不占用 RPC 监听端口、不登记生产预算。四套生成结果和首轮 START 证据见 [configuration_verification.json](configuration_verification.json)。

- 首轮 32 个训练阶段和 7 个混合评测阶段各抽取一个封存的实际 RPC START，核对原始记录 SHA 和完整 RPC 参数。自由速度因子的标准差为 0.05，截断区间为 0.85–1.10。四套配置均接受匹配的实际 START 夹具，拒绝把标准差替换成 0.15 的对应夹具。
- 每套 Java 编译并检查 1,724 行 master 和场景表、矿废品位、道路值、速度 Freeform 函数及绑定端口；拒绝被改动的场景表。四套 Python 配置按生成器逐值重新展开验证。每套 700 个评测槽均与首轮工况哈希、环境种子和 Actor 采样种子相同。
- 四套独立临时账本均验证未提交更新返回空值、越序运行被拒、UNKNOWN 被保存；各自在临时目录创建并恢复 u0，初始 seed 与冻结值一致、优化器状态为空。把首轮评测复制为纯离线夹具时，按新身份重绑后正确汇总 700 对，和 s01 的差值归零。
- 50052、50053 对应的两把进程锁可同时持有，同端口的第二把锁被拒，子进程继承锁成功。尚未用两个真实 AnyLogic 副本做吞吐测试。
- 受保护 PPO 核心前后 SHA256 均为 `8e4cfa31c622f5e33756e304eea3f7526547db72ae93f7d9f00808845d61ef96`。未编辑 `.alp`。
