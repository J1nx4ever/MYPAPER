# 原版 BG128 混合品位训练对照方案

## 本轮要回答的问题

**原版 BG128 和 C128 在每个站都见过低、中、高品位以后，能否在训练未见的品位排列下按物料特性纠偏？** 首轮沿用 1519D RPC、原四类图关系与原边属性、原站点身份输入、原 C128 拼接和原奖励，让训练工况成为预定的主要改动。已封存的标称训练 u32 用于对照。结果用来决定是否进入边属性增强与候选摘要重构。[换位审查](../../../../../../reports/token_attention_001/business_graph_summary_009/generalization_001/grade_swap_state_relation_audit.md)

## 训练工况与批次配比

每班在启动时按计划为 Load0、Load1、Load2 分别设置下列名义品位。班内各站均值固定，保留原矿块级 **±0.5 个百分点**波动和 **500 吨**块大小。车队、拓扑、装卸能力、库存、运速配置与目标使用标称合同。场景标识用于校验与分组统计，模型读取的是实际 RPC 观测中的物理量。

| 训练排列 | Load0 / Load1 / Load2 | 32 批合计 |
|---|---|---:|
| 标称 | 38% / 30% / 15% | 342 班 |
| 循环排列一 | 30% / 15% / 38% | 341 班 |
| 循环排列二 | 15% / 38% / 30% | 341 班 |

**1 个新初始化种子，从头训练至 u32。** 每次更新收集 32 个完整班，依次轮换三工况配额 **11/11/10、11/10/11、10/11/11**。批内 32 个槽位按冻结顺序交错，首批计正式训练。每批用同一个冻结行为 Actor 采样，32 班通过完整性校验后提交该次更新。u16 保留作训练过程检查，u32 是事前指定的唯一主评检查点。[原训练参数](../../../formal_training_001/README.md#L7) · [原 u32 延训口径](../../../training_extension_001/README.md#L1)

沿用原 PPO 的 Actor/Critic 学习率 **3e−4 / 1e−3**、4 epochs、minibatch 32、clip 0.2、entropy 0.01、梯度裁剪 0.5、γ 1、λ 0.95及原成本计算。完整任务仍要求四窗品位合规、矿石至少 16,000 吨和废石至少 4,000 吨。训练采样保留正常结束的欠产及品位超限班。恢复和训练更新使用原目标构建、冻结 old-V、GAE 和提交逻辑。[原训练合同](../../../formal_training_001/README.md#L11) · [目标和判定口径](../../../../../../single_critic_task_query_v1/evaluation.py#L99)

开跑前只读筛查计划内六种排列的库存、路线、装卸能力和窗口处理能力。静态可配性的核对例是按高、中、低源约 **30.435%、33.333%、36.232%** 配料，三种名义品位混合为 27%，对三源各 ±0.5 个百分点的范围仍落在 26.5%–27.5%。这一核对只覆盖材料构成。车辆周转、FIFO 和废石任务的动态可达性另核对，评价时完整保留实际失败班。

## 品位分布与站点排列联合训练

如果首轮目标是得到能直接适应不同品位工况的策略，建议在原模型上采用本扩展版。上面的三排列方案保留为“只改变站点分配”的对照。扩展版从新初始化训练同样的 **1,024 班**。每班先确定高、中、低三类矿的名义均值和矿块波动，再将其分配给物理站点。三个因素做全交叉，避免某个排列暗示固定的均值向量或波动幅度。

| 工况因素 | 训练水平 |
|---|---|
| 高／中／低名义均值 | `38% / 30% / 15%`、`36% / 29% / 17%` |
| 矿块品位半区间 | 三矿源共同取 **±0.5** 或 **±1.0 个百分点**，保持原块生成机制和 500 吨块大小 |
| 品位分配到站点 | Load0/1/2 依次为高／中／低、中／低／高、低／高／中 |

共有 **3 × 2 × 2 = 12 个训练工况**。每个 32 班更新给每工况 3 班，再按下述规则给四个格各减 1 班。对当批短配额排列，减去均值档与波动档的两个同序组合（第一档配第一档、第二档配第二档）。另外两个排列按循环顺序各减去一个交叉组合，依次为第一均值配第二波动、第二均值配第一波动。短配额排列每批轮换。这样每个均值×波动组合每批都有 8 班，三个站点排列各 10 或 11 班。32 批结束后每个工况 85 或 86 班，训练总量保持 1,024。每班配置在创建品位块前固定，模型从当班观测读取 `meanGrade` 和 `gradeHalfRange`。这里的适应定义为**固定 Actor 按可见工况直接调整派车**。班中若发生未观测的分布漂移，需要另行验证其可见性和观测合同。[已有均值和波动工况](../../gen_common.py#L36) · [候选品位与波动输入](../../../../../../grade_commitment_ppo_v1/features.py#L498)

扩大波动前在同一物理路网下筛查所有拟训练和评价配置的可达性，尤其核对废石达产和当窗矿石兑现。按 27% 名义配比，±1.0 个百分点的材料极限已贴近 26% 与 28% 的合规边界，装卸和 FIFO 对可达性的影响另行检查。

在原四个固定独评工况之外，建议追加两个联合留出。暂用 `37% / 29.5% / 16%`、半区间 **±0.75 个百分点**作为训练两档之间的插值例，待物理可达预检后冻结。第一组保持标称排序，第二组使用 `16% / 29.5% / 37%` 的训练未见排列。同一工况给旧、新 u32 各 100 班新配对评估，观察新数值和联合换位下的完整任务及逐窗实际纠偏。扩展版含 1,024 训练班和 1,200 独评班，**拟新增 2,224 班**。若同时纳入一组矿废角色互换，拟新增 **2,424 班**。矿废互换单独报告。[废石角色独立工况](../station_role_control_001/README.md)

12 工况均可行及留出组通过评估，才支持在本研究地质模型和固定拓扑内的适应结论。需要控制“加入均值和波动的额外贡献”时，分别比较固定品位、仅排列混合、联合混合三个训练臂。在使用封存旧 u32 的单种子比较中，以固定检查点差异表述结果。

## 固定独评与判断标准

旧标称 u32 和新混合 u32 都按原随机采样方式固定推理，在以下 **4 个工况，每模型每工况 100 班**。每个评估槽给八个模型与工况组合使用新环境种子和新 Actor 采样种子逐槽配对，物理运行各自使用独立身份。评估种子与本轮训练及历史隔离。

| 评价工况 | Load0 / Load1 / Load2 | 用途 |
|---|---|---|
| 标称 | 38% / 30% / 15% | 检查原工况是否保持。 |
| 已诊断互换 | 15% / 30% / 38% | 用新种子复验已知失败机制，检验换位后能否纠偏。 |
| 留出排列一 | 38% / 15% / 30% | 检查泛化到另一种未用于训练的排列。 |
| 留出排列二 | 30% / 38% / 15% | 检查泛化到另一种未用于训练的排列。 |

主指标为**每个留出排列的完整任务率**，分开报告并给配对改善与退化班数。建议本轮阶段门槛为新模型标称 **至少 95/100**，三个留出排列**各至少 90/100**。这是建议的工程判定标准，正式冻结时确认。另报四窗逐窗上下越限、RMSE、矿废达产与平均等待，附按班次配对的不确定性区间。读取首窗实际矿源 Q/M，检查成功能否由派车随品位角色变化来解释，尤其是不同工况下低品位源实际进窗量。按班次与训练种子分别解释重复，避免以决策或窗口数替代训练种子。

旧 u32 对照锁定在[已封存源检查点](../../../training_extension_001/README.md#L3)。这个单种子对照回答两个已训练策略谁在留出工况表现更好，统计不确定性主要来自评估槽。若结果达到门槛，原结构具备作为混合品位基线的资格。若仍出现方向性偏派，再在相同混合训练分布下比较增强边或候选净兑现摘要。若需单独估计训练分布效应，后续用新固定品位臂与混合臂配对初始化并重复训练。
