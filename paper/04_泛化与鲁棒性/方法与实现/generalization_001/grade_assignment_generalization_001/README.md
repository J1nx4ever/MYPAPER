## 要解决的问题

**在固定矿山拓扑下，矿源品位角色改变时，策略能够按候选动作预计在目标窗口兑现的吨位和品位方向纠偏，并继续兼顾矿石、废石和等待。** 互换测试定位了两个相互关联的缺口。训练固定了站点与品位的对应关系，使站点充当捷径。当前摘要告诉策略已经承诺了什么和候选站有什么，但候选会如何改变本窗、下窗的配矿，需要网络从固定工况中自己推断。首班前向还能独立测出显式站点 one-hot 的作用。[状态、身份和关系审查](../../../../../reports/token_attention_001/business_graph_summary_009/generalization_001/grade_swap_state_relation_audit.md)

| 改动 | 解决的问题 | 判定依据 |
|---|---|---|
| 交叉训练站点与品位角色 | 训练样本无法区分“跟随物理品位纠偏”和“跟随熟悉的站点” | 保持原结构，仅改训练分布，比较留出排列的完整任务和窗口违规方向。 |
| 给候选动作提供按窗净影响 | 现有站点品位、ETA 和派载吨位未直接表达实际可能入窗的量及排挤效应 | 相同状态下的增量与来源可复算。保持训练分布一致，检验是否额外改善留出工况。 |
| 验证站点身份和公共摘要尺度 | 显式编号可能代替品位角色，小吨量品位比值和接近零的余量分母可能造成过强响应 | 分别对照纯编号诊断、去直接身份、公共比例字段改动，独立测量每项效果。 |

## 状态和关系合同

状态合同保留 1519D RPC 及实际合法掩码。站点键与路线物理位置用于构图、引用、统计和动作执行。矿废类别用于兼容判定。名义均值和半区间是工况输入，装载时可见统计带已知位，已载货品位和 FIFO 批次品位属于可见物料事实。低品位或稀释作用由候选相对目标的按窗净金属贡献表达。运输、承诺、服务、物料兼容四组继续传播事实。动作假设由候选计算单独构建，每个候选从同一快照出发，当前事实边与已发生的承诺保持明确来源。[1519D 及关系定义](../../research_definition_v1_001/architecture_math.md#L7)

第一步复用现有矿源场景参数。训练可采用 `(38,30,15)`、`(30,15,38)`、`(15,38,30)` 三个循环排列，使三个物理站都覆盖低、中、高角色。评估留出 `(15,30,38)` 和其他未见排列。筛查装载能力、路网、矿废任务及控配矿窗口是否可达。当前互换已经用于定位机制，后续继续留出可作为机制复验。确认性评价再冻结尚未用于选方案的新组合和种子。如果训练包含某个排列，该排列的新种子结果应按已见配置的独立评价报告。[场景配置入口](../gen_common.py#L36) · [现行 AnyLogic 工况参数入口](../manual_anylogic.md) · [独立训练与测试工况](https://proceedings.mlr.press/v97/cobbe19a.html)

## 摘要重构

### 首版在共享候选评分中增加按窗净影响

在同一快照用 `physical_realization_v1.engine.estimate` 计算仅有现存承诺的基线，再给每个合法候选独立增加该车，分别得到本窗和下窗的总处理量与总金属量。两种投影总量做差得到 `ΔQ` 和 `ΔM`。该差值包含候选自身兑现和被挤出的旧料。对候选自身、既有物料变动和总量保留独立校验口径，便于用真实物料记录解释。

| 首版输入 | 含义 |
|---|---|
| 每候选、每窗 `ΔQ / 193` | 净矿石破碎吨位增量，以最大单车载量定标。 |
| 每候选、每窗 `(ΔM − g*ΔQ) / 1.93` | 相对目标品位 `g*` 的净金属量增量，1.93 金属吨对应 193 吨 × 1 个百分点。 |
| 每候选、每窗 `ΔW / 193` | 净废石交付吨位增量。 |
| 每候选、每窗 `valid` | 当前预测有效位。有效零变化记为有效，估计缺失的数值用零占位并标记无效。非法动作与无下窗分别由已有合法掩码和窗口活动位表达。 |

首版在现有候选 10 维编码旁接入两窗共 8 个数值，四候选共用同一参数化的候选评分。公共 88 维和 Critic 输入作为对照保留。上下限余额可以用 `ΔQ`、`ΔM` 和实际阈值从同一投影计算。审计同时保存估计质量和可用性统计，在线推理读取当前可见快照。候选 ETA 路段、铲装与交通采用既有条件估计，验收把预测误差与实际物料结果区分开。BG128 的零吨 FIFO 规则复用在私有派生副本。特征版本、证书和新 Actor 配置一并冻结，训练前向、在线推理与录后重放使用相同特征计算。[估计器](../../../../../physical_realization_v1/engine.py#L499) · [已有物理表示](../../../../../physical_realization_v1/representation.py#L18) · [私有 FIFO 处理](../../../../../single_critic_task_query_v1/c_features.py#L74) · [共享评分与特征合同](../../../../../business_graph_summary_v1/models.py#L122)

首班第 2 次决策可作为算例。若候选的 91.7 吨按名义投影全部在首窗处理，Load0、Load1、Load2 对 28% 上限金属余额的变化分别约 **+11.92、−1.83、−9.17 金属吨**。Load0 使已投影组合由 38% 向合规带靠近，预计仍约 29.16%，后续还要补低品位物料。该算例检验排序的物理方向，整班结果由后续调度与兑现共同决定。[首班封存观测](../../../../../runs/bg128-u32-generalization-20261119-001/evaluation/grade_swap/episodes/run_9991101/samples.h5)

### 公共摘要和站点身份独立消融

如果在混合品位训练下仍发现公共比例字段过度支配排序，单独检验任务块调整。保留实际已破碎、FIFO、未来名义承诺三层的 Q、M、吨位尺度、上下限余额、余时、余量、欠产和有效性。让 `M/Q` 和 `required_grade_*` 的原值保留用于诊断。网络对照优先用固定吨位尺度的金属余额来体现 147 吨高品位与接近满窗的差别。若需保留名义凸包信息，使用不除以剩余容量的缺口量。例如剩余量为 F，合法矿源最低品位为 `g_min`，上侧缺口用 `M + g_min·F − U(Q+F)`，其中 U 是品位上限。同时保留有效位、F 和合法矿源范围，表达“填满名义剩余能力”的前提。[现有比例与余额计算](../../../../../grade_commitment_ppo_v1/features.py#L475)

另做完整等价重标。同步置换装载节点、拓扑端点、车辆目标、站点引用、候选槽与输出，逆置换后比较同物理动作的概率。纯重标在诊断图与对应编码合同内实施，保持固定生产路网的线上 schema 校验。作为另一种测试，固定物理几何与引用，仅改变矿源品位，检查候选余额方向和排序。若要降低身份依赖，先同结构地消融直接站点 one-hot，再单独检验引用中的类别编号。固定几何本身也可区分矿点，身份消融仍需与交叉品位训练配套。[站点引用和显式身份](../../../../../business_graph_summary_v1/encoder.py#L137)

## 验证顺序与输出

1. **封存快照离线检验。** 核对现存承诺基线。覆盖低高源等吨位替换、同品位异 ETA、越过窗口截止、候选挤料、无下窗、废石和预测无效。验证 Q/M 守恒、净量分解、合法掩码隔离、无未来事件输入及在线与录后同源。选中动作的估计误差可用物料事件检查，未选动作的真实闭环结果需要独立实跑证据。[既有条件投影离线验收](../../../../../reports/physical_realization_representation_001/README.md#L5)
2. **区分训练覆盖和动作表示。** A 用原固定工况和 BG128，B 用同预算的混合品位训练与原 C128，C 在 B 基础上只加候选净影响。B−A 比较训练覆盖增量，C−B 比较候选表示增量。同一推理模式、任务目标、评估槽和配对种子。报告标称及留出组合的完整任务、四窗品位上下超限、矿废达产与等待，班次和训练种子分别统计。若 B 已达到预定工况目标，C 的价值应由其额外收益和预测开销决定。
3. **按结果验证身份和公共尺度。** 在相同训练分布下将两个因素分别单独调整。保留观察到的严重超限幅度。若要比较品位成本封顶，另用等预算的目标对照，避免与表示变更同时引入。目标合同与训练报告以班次实际结算为准。[现行品位成本](../../../../../single_critic_task_query_v1/targets.py#L35)

本方案是离线审查之后的实现与验证设计。实验实施按最新合并账本登记独立身份与预算，训练复用受保护的 PPO 核心。
