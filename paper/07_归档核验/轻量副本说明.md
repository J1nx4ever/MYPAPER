# 代码与小型结果的独立副本

文件清单记录每个已复制源文件一行，包含相对项目根目录的原位置、相对 paper 的新位置、文件字节数和 SHA256。每份副本均为独立的普通文件，复制时分别读取源和副本核对字节摘要。历史报告中的绝对路径、配置引用及代码中的相对导入保留原文；需要打开原件时使用清单中的原位置。[文件对照清单](file_map.tsv.gz)

原位置索引列出运行目录、物料目录、冻结启动包、逐班明细报告、既有图件和 AnyLogic 模型等入口。大文件与运行过程数据继续留在原位置。目录是否已完成、是否为准备或修复活动，按阶段一总表的回执核对结果判读。[原位置索引](原位置索引.tsv)

六个分类入口和本说明是归档导航。文件对照清单覆盖从既有仓库复制的文件，阶段一新编制的总表及其核验包由单独入口提供。使用以下命令复核现有轻量副本。

```bash
/home/jinx/miniconda3/envs/anylogic-env/bin/python -B paper/07_归档核验/snapshot_sources.py
```
