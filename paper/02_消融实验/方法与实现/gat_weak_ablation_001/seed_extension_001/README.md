# BG128 与一轮 GAT＋逐节点 MLP · s04/s05 配对扩展

本轮新增两对训练日程，补齐原有 `s01–s03` 的 Full 与 `1-Round GAT + Node-MLP` 对照。按 `full-s04 → gat1-s04 → full-s05 → gat1-s05` 串行执行。四组各从独立 `u0` 开始，旧 `s04` 的运行、预算与回执保留供审计。每对逐班沿用对应历史计划的 1,024 个训练工况，两种策略各自采集 on-policy 轨迹。

| 配对日程 | 两个策略 | 每个策略的训练 | 每个 `u32` 的独评 |
| --- | --- | ---: | ---: |
| `s04` | `full-s04`、`gat1-s04` | 1,024 班 / 32 次更新 | 7 工况 × 100 槽 |
| `s05` | `full-s05`、`gat1-s05` | 1,024 班 / 32 次更新 | 7 工况 × 100 槽 |

四个新检查点按原混合 `s01/u32` 的评测顺序，逐槽复用工况、完整 RPC 配置、环境种子和 Actor 采样种子。每次物理运行使用本次登记的 run 和 recording 身份。主结果仍为五个共同留出工况，`nominal` 与 `grade_swap` 单列。以匹配训练日程为单位汇报完整任务率、四窗合规、车队累计等待和矿废达产，逐窗品位误差随评测表提供。结合已有 `s01–s03` 检查完整任务与废石达产的配对差值是否随训练日程波动。

运行规模为 **6,896 班**，其中训练 **4,096 班**、固定检查点评测 **2,800 班**。准备阶段不登记物理班，启动后以实际登记为准。 [AnyLogic 手工接入](manual_anylogic.md) · [启动身份及阶段配置](prepared_001/launch_identity.json) · [预算合并入口](extension_budget.py)
