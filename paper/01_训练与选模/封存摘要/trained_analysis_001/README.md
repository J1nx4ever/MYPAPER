# BG128：独立推理、训练目标、梯度与业务干预分析

2026-11-18，Asia/Shanghai。采用训练期间预先选定的checkpoint13，已完成100个新seed的独立推理：18625个决策、400个非空窗口，零参数更新。随后所有分析与A/B/C均为离线工作，没有新增仿真或训练。

**整体判断：这版图＋C128已经形成明显更有效的业务策略；但不能宣称训练稳定收敛，也不能把合理的业务响应都归功于GAT。剩余问题主要是首窗口的处理时序、后期仍较大的策略更新，以及图和摘要在不同业务条件下利用不均衡。**

## 2. 两个失败班次：总供料组成合规，已处理组成失配

两个失败均发生于首窗口，其余三个窗口全部合规，无矿石/废石短缺。

| run | 首窗实际处理吨位 | 实际处理品位 | 窗末FIFO剩余吨位 | FIFO品位 | 首窗已卸全部物料的静态混合品位 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 9950012 | 4170.37 | **0.25821660** | 339.63 | 0.36158511 | **0.26600097** |
| 9950029 | 3690.57 | **0.25911785** | 332.13 | 0.33381905 | **0.26528539** |

两班已经进入FIFO的总物料平均品位均在[0.26,0.28]，但较高品位料留在截止边界的FIFO中，实际被处理的组合跌出下界。第二个失败班的低品位处理占比37.83%，并不高于100班首窗中位数38.61%；因此不能统一解释为“选了太多低品位Load”。应重点检查**高品位补料能否在当前窗口截止前到达、排到并被处理**。

静态混合仅含首窗已卸的物料，不包含未来到货；它不是可实现的额外处理反事实，也不证明提高处理能力就一定解决。窗口边界没有完整Truck快照，不能补猜精确在途承诺。证据见[首窗口流水报告](../checkpoint_evaluation_001/trained_analysis_001/first_window_failures.md)与机器明细。

## 3. Reward：同一目标实现正确，成本份额不是梯度份额

全部16批成本、MC、冻结价值GAE及统一优势标准化已重建并闭合。没有发现Actor/Critic目标不同步、重复结算或把旧RPC reward当作另一套目标。当前联合成本仍为四窗deadband=.004、scale=.006、cap=2、空窗2，矿/废短缺8/8，等待0.2×累计车辆等待秒/28800。

| 平均每班成本 | 选中策略u13的32班训练观测 | 100班独评 |
| --- | ---: | ---: |
| 品位 | 0.193457 | 0.202755 |
| 生产短缺 | 0 | 0 |
| 等待 | 0.128891 | 0.124757 |
| 联合 | 0.322349 | 0.327511 |

u13训练批的128个窗口中105个（82.03%）在零成本带，23个仍有品位成本；品位/等待成本约60%/40%。零带内停止追中心的目标确实在发挥作用，同时保留了带外纠偏信号。不能因为等待成本占40%就推断它贡献40%的策略梯度，也不能据此直接继续提高等待权重。

按冻结量纲，在未触及cap的带外区间，某一个窗口额外0.001品位偏差增加约0.1667成本，相当于24000车辆秒等待。当前目标仍明显优先纠正带外品位；这是业务取舍，不能只由系数0.2的字面大小或成本份额判断权重是否合适。

当前主要风险是延迟信用：奖励结算基于窗口实际处理结果，而补料、到达、FIFO顺序发生在更早决策。提高品位系数并不能自动让网络识别“高品位补得太晚”；首窗时序证据比单看总供料比例更有解释力。

## 4. 收敛：学习明显，但后期仍在移动

行为策略u0到u13的联合成本由4.52180降至0.322349，下降约92.87%。u14/u15的后续采样成本又升至0.452339/0.491784。最终u16没有后续真实采样，不能用其训练summary声称最终策略的业务表现。

更新14/15的近似KL约0.01963/0.02602，clip fraction约0.2877/0.3817；Actor平均裁剪前梯度范数约0.735/0.711，高于0.5阈值。均值不能恢复逐minibatch触发裁剪的频率，但这些记录与每次仍约1.9的Actor净参数变化共同说明更新没有趋于停止。32班均值也有采样噪声；因此可以说“后期有波动和回退风险”，不能证明全局发散或稳定收敛。

Critic MSE大幅下降同时，MC目标方差也由约3.84降到约0.0408。独评的目标方差0.04996、残差方差0.04154，EV仅0.16849；较低绝对MSE尚不意味着较强的相对价值解释能力。主表使用pooled EV；逐班EV简单平均为负会被低方差班次放大，不据此声称整个Critic崩溃。

## 5. 实测梯度：需要区分直接成本、价值自举和Adam

在u0/u6/u10/u13/u15的原始32班上，使用相同冻结策略、相同联合优势标准差，离线重算完整batch的更新前策略梯度；ratio约为1，无clipping激活。成本GAE、价值TD/自举项和统一标准化逐项加和闭合，最大梯度相对闭合误差约1.1e−6。没有执行optimizer.step。

| --- | ---: | ---: |

| 联合策略项 | 0.221624 | 1 |
| 熵正则项 | 0.005614 | 见完整诊断 |

品位/等待直接梯度范数比约12.0，其他诊断点约16.7—29.7（u0约19.1）。等待项在多个批次与联合方向相冲突，不能将各范数归一成可相加百分比。GAE的价值项包含未来价值自举，不只是当前V(s)的减baseline；它携带整个联合目标，不能再按品位或等待进行归属。这个批次的Actor方向对价值项依赖很强，值得联合独评EV审视。

这些是**冻结更新前参数上的完整batch直接梯度**，不是四个epoch中每个minibatch的梯度，也不是Adam实际更新的成本贡献。已测得相邻checkpoint的总净参数增量，但没有逐成本Adam更新归因；不把12倍解释成“Adam给品位12倍贡献”。完整五点结果见[梯度与收敛报告](training_reward_convergence_gradient.md)。

该历史点上，B的Load1 H2变化L2为1.90563，C的三个矿石Load H2变化约0.00125—0.00147。两层路径数值可达，不等于最终评分有效依赖图。C128在本轮不能轻易删除；同时也不能据C的一次干预判定所有下游信息都被GAT忽略。

**C还存在训练支持域限制：** 正式512班、16个phase的Dump0速率均固定2500 tph；1250属于未训练参数外推。C128的工程FIFO/窗口处理投影本就根据速率重算，因此会自然响应，策略再利用这些投影。图支路弱响应可能与训练中缺乏速率变化有关，不能直接判定“两层GAT传播失败”。证据和其他机制限制见[完整训练后干预报告](../trained_intervention_001/audit_report.md)。

**数量重复和信息多路径必须分开。** 独立21维oracle没有发现车辆或吨位重复计数；候选未污染事实图。同一在途事实可以同时进入Dump0的H0数量、Truck→Dump→Load消息、候选直接Dump读出和C128，这是多视图编码。A中仅阻断Truck1→Dump0第一层边，Load2 H2变化并未消失；去掉material消息则由0.024159降至0.000304，说明Dump端已有数量提供了替代传播通道。边阻断和Graph/C128混合读出都是机制探针，不是可实现的物理状态或唯一因果归因。

## 7. 建议的下一步

1. **先保持当前reward和两层结构，控制后期更新幅度。** 下一次受控训练可只将Actor学习率3e−4降至1e−4，其余保持一致，检查KL、clip fraction、训练监控成本及预先固定的独评。若仍不稳，再单独比较epoch数；不同时更换多个业务权重。
2. **优先处理首窗的“能处理到多少”，而非直接提高品位或等待权重。** 针对现有FIFO顺序、窗口剩余时间、高品位在途和处理投影，检查现有表征是否改变相对动作评分；聚焦两例真实失败和同分布成功状态。静态总供料合规不能代替当前窗处理合规。
3. **保留C128，扩大图/摘要机制核验。** 在更多真实状态上重放承诺和下游压力变化，统计方向、幅度和支路抵消；先确定缺乏训练变化还是融合读取问题，再考虑融合调整。不要仅凭本点增加GAT层数或强制注意力占比，也不把C128去除作为已获证据支持的改进。

本报告没有修改reward、PPO核心、模型或冻结输入，也没有启动下一轮实验。固定100班业务独评、冻结梯度诊断与原始观测物理分支分别提供性能、优化和局部机制证据，三者不能互相替代。
