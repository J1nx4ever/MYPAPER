# 西采场装运卸演示

在 AnyLogic 8.9.0 打开 [WestPitHaulage.alp](/home/jinx/Models/WestPitHaulage/WestPitHaulage.alp)，右键项目树的 **Simulation → Run**。工程同时读取同目录的 `west_pit_aerial.png`。模拟班长 8 小时，默认按 75 倍时间显示，可用运行窗口的暂停和倍速控制。

## 现场检查

1. 打开 **Main** 查看西采场道路、铲位及场外卸点。浅色实线沿底图上可见的台阶估绘。右侧单独绘制矿石粗破、矿石堆场、废岩短倒和Ⅱ-3直排的出口。停车点和备用铲泊位为示意。图形距离采用展示比例，行驶时间使用对应线路公里数与空、重车速度计算。
2. 运行 **Simulation**。点击 **下一辆车** 选择车号。观察一辆矿卡从空驶、待装、装载、重驶、待卸到卸载。图上车厢颜色随载荷变化。装卸点按到达先后、单服务位放行，同一节点可能有多车图标重合，队列行给出排队数。
3. 观察一辆重车抵达卸区。卸完时对应卸点增加这车实载吨，车上载荷归零，完成趟数加一。粗破数字计矿卡送达吨位。矿石小计含粗破与堆场，废岩小计含短倒与直排。
4. 在班末核对“累计已装 = 四处已卸之和 + 车上载荷”。班末在途包含重车行驶、待卸与正在卸载的整车物料，口径以装卸服务完成时点为准。物料差额应为 0 t。

## AnyLogic 模型位置和修改方法

本次新增独立工程。下表给出工程内的默认值、修改位置及验证方法。

| 对象位置 | 默认内容与可做的修改 | 影响与验证 |
|---|---|---|
| Main → Parameters → fleetSize | 9，修改默认值后重新运行 | 开班车数与拥堵变化。队列计数分母应等于设定车数。 |
| Main → Parameters → activateShovel5 | false，设为 true 可启用备用车铲工况 | 备用点加入派车候选；观察第四装点列表和车辆追踪。 |
| Main → Parameters → emptyKph、loadedKph | 32、23 km/h，均应大于零 | 只改一项并比较相同起终点的行程时间。 |
| Main → Parameters → loadBaseSeconds、unloadBaseSeconds | 220、88 秒 | 改变装、卸服务时长和等待。按追踪栏观察实际开始、结束时间。 |
| Main → Parameters → shortHaulShare | 0.35，取 0–1 | 控制 13# 情景的短倒份额。取 0 时该装点的废岩均走直排。 |
| Main → prepareTrip、driveEmpty、driveLoaded | 分别定义派单、空车路线时间和重车路线时间 | 对照车号、目的地、路线及到达时刻。 |
| Main → Advanced Java → Additional class code | directKm、shortKm、oreCrusherKm、oreStockKm | 建议以同期车次或路线实测公里数替换相应整条线路参数。 |
| Truck → statechart；WorkStation → Advanced Java | 车辆状态转移；FIFO 等待队列和单服务位 | 两车到达同站时，观察前车先开始、后车随后获服务。 |
| Main → finishShift；Simulation → Model time | 班末结算 28,800 秒，实验在 28,800.001 秒停止 | 查看班末控制台摘要、各去向吨位及物料守恒。 |

验收活动的独立身份、配置 SHA256 和输出目录见[运行清单](launch_identity.json)。项目默认关闭逐车次事件输出。仅指定验收配置时写入开班标记及班末汇总。
