2026-11-25。这里将“西矿区”落实为白云鄂博铁矿西矿内的**西采场**，首版再收缩为一个能独立核对的运输作业单元。目标是在西采场复用论文的图调度、物料承诺和 FIFO 结算方法。先查明现场如何决定入破碎站或直排，再确定是否需要扩展 BG128 的动作。AnyLogic 接线和验收见[手工清单](manual_anylogic.md)。

## 同一 Te 目标下的台账标定案例

首个现场应用可以限定在西采场同一矿石破碎线、同一 Te 生产口径和固定目标的连续班段。`Te` 暂沿用现场叫法，需用班前生产或配矿指令确认指标定义、目标值、容许带及生效时段。班次按作业单元、破碎线和目标筛选，保留其中的正常波动、超限和欠产。优先取一班检验数据能否关联，再用独立完整班次验证标定。

**任务。** 每次空车可派时，按当时可见的工作面品位估计、在途承诺、队列和粗破仓状态选择装载点。矿石按现场规则去该矿石粗破，废石按现场规则直排。主目标是降低实际破碎窗口品位偏差及越界率，核对有效窗数、矿石吨量与累计等待。矿石最小供给及现场规定的剥离任务作为比较约束。共享车辆、道路或装载资源的废石运输继续占用资源。首轮两策略共用同一废石派车规则或已知资源安排。独立的废石车队按背景交通建模。

| 台账信息 | 可用于标定或核对 |
|---|---|
| 当班生效的 Te 目标与容许带，班起止，装点、车辆出勤与粗破运行记录 | 固定同一个生产任务和当期可用资源。若仅有事后平均品位，按研究假设设置目标并标明来源。 |
| 矿石及共用资源的废石车次，含车号、装卸点、净重、装完、到卸点、卸完等时间 | 还原材料走向、车队与 OD（起点–终点）循环。需要单列等待和服务时间时，补队列到达及服务起止。首版可用标定后的运输时长及关键共用路段建立等效网络。 |
| 按工作面、矿批或有效时段的原矿化验、记录可用时间及出矿量 | 检查矿源之间或时段之间有没有可调节的品位差异。决策只读取当时已有的估计，事后化验用于标定或结算。 |
| 粗破的分时处理量与同口径品位，班初仓内与在途物料，外部来料 | 用实际破碎时间核对各窗矿量 $Q_w$、金属量 $M_w$、品位 $M_w/Q_w$ 及质量守恒。班均化验只能核对班均品位。 |

**首个判断。** 固定的是目标且实际批次品位有可辨差异，同时派车能改变哪个来源的料进入窗口，才具备配矿策略对照的条件。若各批次真实品位相同，每个有产出窗口的质量加权品位相同，该班可验证运输、供料和等待。可用源头品位与可达矿量先检查现场目标带的可行性。单一班均值、舍入值或合样结果无法判定各批次是否相同，也无法唯一反推矿源品位和 FIFO 历史。

**对照。** 先用现场派车或可核实的现场规则复现班次，核验运输周转、分窗粗破吨位和品位。随后在同一标定环境和开班状态下比较 BG128 与现场规则或配矿规则。保留共用的外生班计划和资源条件，各策略自行产生后续行程、队列与破碎批次，按相同吨位条件报告品位偏差和等待。一个班次作为案例与接线核验，跨班比较使用未参与标定的班次。 [原论文方法与结算口径](../research_definition_v1_001/paper_review_20261124/README.md#L13)

## 西采场首版边界

- **作业面。** 先核对西采场 5#（北帮）、13#（南帮）、15#（底部）、18#（南帮）在同一时期的车次。按真正共同作业的工作面选装载点，分别记录铲号、台阶、当班物料、供料品位和允许去向。若资料无法证明有三个同时供矿的工作面，按实际可用矿源修正模型范围，检查合法掩码与候选占位的语义。
- **车队和路网。** 选择同一调度单元的实际车组，核对空重车路径、共享路段和排队位置。兼容模式需要实际路由可投影到固定图。只运行实际到岗的车辆，现场常用的 220/236 吨车若会合法满载，采用新版观测合同。
- **两处计量终点。** `Dump0` 对应正在评估的矿石破碎线，`Dump1` 对应一个有明确位置和规则的直排点。1635 m 矿石破碎站是初设中的查找线索，实际站号和去向以所选时期车次核对。若两条路实际分别是**岩石短倒破碎转运**和**岩石直排**，这两条都是废石运输去向。矿石入粗破及品位结算需要第三条物料流，或先取独立的废石运输子问题。
- **计量范围。** 用同一部位、同一时间段的班计划、破碎处理和实卸数据。选区只贡献粗破一部分来料时，必须能辨认本区来料及其余外部来料，或另选独立计量时段，才能对照同一粗破端的品位。 [初设西采运输与道路，正文第 93、134–135 页](</home/jinx/桌面/生产资料/1.初步设计（1000万t）.pdf>) · [西采场设备分区](</home/jinx/桌面/生产资料/自有设备生产区域.xlsx>)

## 判断卸载去向是否构成新的研究问题

| 现场实际规则 | 应接入的动作 | 对研究的影响 |
|---|---|---|
| 每车去向由物料类别、采区指令或固定流程唯一指定。例如矿石入破碎、废石直排。 | 保留四个装载点动作，由环境执行现场指定的去向。 | 属于现场参数化与固定规则适配。现有任务已经按物料将车送至破碎站或废石卸点。 |
| 同一装载点会出不同物料，装完才确认类别，每类依然只有一个合法去向。 | 装载完成后按当时可获得的物料分类选路。若同一铲班内混采，环境需按实际批次表达物料。 | 增加物料识别时点及去向不确定性。现有按站固定 `isOre` 的假设需要调整，策略动作仍可只有装点。 |
| 同一批料在当时的现场规则下具备两个合法去向，调度可以选。 | 增加卸点动作。若装完才知道载荷、品位估计或两边的可用性，在装载结束后选 `入破碎站 / 直排`。若这些信息在派空车前已知且目的地必须先承诺，可选合法的 `(装点, 卸点)` 组合，最多 8 个。 | 形成装点与卸点的联合调度。去向改变破碎供料、FIFO 顺序、窗口品位、车辆周转与矿石回收。 |

以历史车次核对每个物料类别在同一作业规则下的合法去向、指令下达时间、决定人和当时可知的物料信息。看到同一铲出现在两个目的地，只能证明两条路径都发生过。需要确认某个具体决策时点的同一批料是否允许走两边。一次性定性的首批样本可取连续 2–3 班，且覆盖可能有双去向的物料。

## 联合调度版的研究设计

若现场确认有双去向，首选保留空车选装点，再在装完、驶向卸点之前决定去向。已有业务图和 FIFO 投影提供状态结构。把 C128 的固定兼容卸点改为对合法目标分别算到达、排队和兑现影响，构建两个候选评分。现有冻结 `s02/u32` 可作为固定去向参照。卸载动作需由新策略或明确的现场规则产生，学两个决策阶段时需训练并独立评价新的策略合同。

可派掩码使用现场物料类别、品位规则、路线和卸点可用性。每车一次提交目的地与相应的在途承诺。入破碎吨量在实际处理时计入品位与产量。直排分物料类别计量，合法直排的可选含铁料另计金属量，现场有回收约束时按约束计量。核对 `期初库存 + 入库 = 实际处理 + 期末库存` 的矿石吨与金属吨，并在装运边界核对 `开班在途 + 本班装载 = 入破碎卸达 + 直排卸达 + 班末在途`。卸载成功后才计入去向交付。以上守恒以所定义的业务边界和同一物料分类为准。

1. **历史复现。** 用前段完整班次校准路线、服务和破碎输入。用后段独立班次检验现场规则仿真能否复现实绩，检查线路运量、处理吨量、品位和等待。样本范围和误差容许值按记录覆盖与现场计量精度预先确定。
2. **新动作是否有价值。** 在同一生产输入下比较现场固定去向规则与允许双去向的规则。先统计确实处于双去向状态的车次及材料，报告矿废、分目的地物料与等待，观察是否发生回收或产量代价。
3. **策略是否有价值。** 给现场规则、具备卸点控制的规则/运筹基线和新 BG128 同一套可见信息、合法去向、资源与评估口径。对同一批场景配对评估。现场历史用于检验仿真可信度，方法差异按仿真结果报告。 [当前强基线评估](../baseline_comparison_001/or_paper_comparison_001/paired100_strong_001/manual_anylogic.md#业务与算力结果)

约束和处理能力先做离线可行性筛查，所用目标、矿源和路由取本案例实际值。原前置验算里的 4,000 吨矿／窗、1,000 吨废／窗、27% 是标称假设，原脚本只作建模参考。车次实绩作为外部标定和验证材料。策略闭环开始后，每个动作的后续状态由仿真推进。 [原可行性验算口径](../../../../ore_waste_parameters_v1/参数设计与前置验算.md#L141)
