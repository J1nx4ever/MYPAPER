# 3e-4/u13 首窗失败发现批次

按用户授权采集 100 班。环境及 Actor 采样 seed 均为新值，固定 BG128/u13，Actor LR 为原训练的 3e-4，保留原 Reward、常规随机采样、GAT、C128 和物理配置。在同一批运行中发现多少首窗失败均按登记顺序完成 100 班。模型与优化器更新为零。

保留 100 班四窗品位、产量、车队等待、原成本和任务合规。主观察量是首窗失败数和失败 run 的完整列表，偏低、偏高、空窗分别标记。后续候选分析读取失败班封存的 RPC 观测与物料日志。首窗品位合规沿用 [0.26, 0.28] 及原阈值规则。新旧 100 班分开报告，各有独立种子清单。

本批得到的失败轨迹可用于后续寻找物理锁定前的合法替代动作。实际替换的验证仍需从对应失败班原样复现，另冻分支身份与预算。既有两个反事实只支持其对应状态和原随机耦合下的局部证据。发现批采用现有工程上的 HDF5 RPC 数据和紧凑物料日志，供共同前缀验收。逐请求和逐 transition JSONL、rollout 快照及全量物理事件记录均关闭。
