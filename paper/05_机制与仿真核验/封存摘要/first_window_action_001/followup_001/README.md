两个早期状态都存在已实跑验证的修复动作。冻结 3e-4/u13 在两个状态都将 Load0 排在首位，实际随机采样选择了其他站点。两个原派车批次也都赶上首窗，修复涉及处理时间和整个窗口内的吨位、金属量组成。
