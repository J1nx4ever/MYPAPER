## 原始变化先于 GAT 传播

Load 的原始 47D 包含 local20 与 27 个车辆列表槽。local20 中也包含预留吨位、铲装资源占用、装载车辆数等业务汇总，不能将它全部解释成独立于邻居关系的“纯自身固有状态”。

|Load|原始 local20 与业务事实变化|服务列表|明确数量变化|
|---|---|---|---|
|Load0|矿量、预留量、分配游标及已知块信息变化|Truck3 → Truck1|预留吨位 +46；入段车辆 −1，出段车辆 +1|
|Load1|铲装忙/装载数 1 → 0；剩余量/预留/已装量变化|Truck7 → 空|预留 193 → 0 吨，预留车辆、服务车辆、在节点车辆各 −1，出段车辆 +1|
|Load2|铲装忙/装载数 1 → 0；剩余量/预留/已装量变化|Truck5 → 空|预留 147 → 0 吨，预留车辆、服务车辆、在节点车辆各 −1，出段车辆 +1|
|Load3|原始 47D、21D 数量完全不变|Truck4 → Truck4|无|

Load3 的 H0 仍发生微小变化。其引用的 Truck4 的 `loadAge` 和四个运动历史 age 字段增长，Truck4 的基础内容编码因此变化；这些内容在 GAT 之前已经经 service 引用和地理节点在场车辆编码进入 Load3。故“Load 原始字段不变”不等于“Load 的 H0 必须不变”。没有用 T1 的字段补充 T0。

## 内部路径冻结的定义

在 T1 计算中，单独将目标 Load 的下列内部输入替换成 T0 同位置张量，其他节点输入、原始观测及 G1 全部保持 T1：

1. `site_final[0:16]`：local20 的基础投影。
2. `site_final[22:150]`：车辆列表、服务、准入、FIFO 与标志内容。16:22 的规范站点身份不替换。
3. `site_final[150:176]`：地理节点内容、身份与存在标志。
4. `quantity_projection` 该 Load 的线性输出：21 维确定性数量投影；替换在 ReLU 之前进行。
5. 上述四组同时冻结。

这类混合张量只用于诊断计算通道，不是物理自洽的新观测，不供训练。所有四组同时冻结可逐元素精确恢复目标 Load 的 H0(T0)，脚本对此做断言。之后仍在 G1 及其他节点 H0(T1) 上传播，因此 H2 不应被要求恢复 T0。

`raw_sensitivity.csv` 的 `baseline_T1_vs_patched_l2` 是冻结该路径引起的输出改变量；`T0_vs_patched_l2` 是冻结后距真实 T0 的剩余距离。两者是不同量，受 ReLU、LayerNorm、注意力以及交互影响，不能相加成信用贡献、不能转换成占比。

|角色/目标|冻结 local20 路径的 H0 响应|冻结业务引用的 H0 响应|冻结地理的 H0 响应|冻结数量的 H0 响应|
|---|---:|---:|---:|---:|
|Actor Load1|0.040441|0.188916|0.069417|0.118124|
|Actor Load2|0.033348|0.219154|0.051152|0.111468|
|Critic Load1|0.088685|0.252355|0.069840|0.163397|
|Critic Load2|0.086557|0.237483|0.049953|0.162315|

例如 Actor Load2 四组都冻结后，H0 与 T0 精确相同，但 H2 距 T0 仍为 2.250775（真实 T1–T0 距离 2.302036）。这表明在此固定初始化上，仅恢复该 Load 的初始表示，无法复原图更新后的表示；其他节点输入和图关系也在改变数值传播。不能以两个距离作减法得到严格因果贡献，严格的 H0/邻居/图归因由单独的三因素诊断提供。

所有历史快照文件及 PPO 核心 SHA 在运行前后相同，各模型参数摘要在全部补丁前后相同。完整原始字段差异、21D 数量差异、各块实际变化、被引用 Truck 基础表示变化及全部 H0/H1/H2 补丁结果在同目录 JSON/CSV 中保留。
