# BG128 可解释性脚本离线验证

使用历史 Nominal 与 Swapped 工况，各读取 BG128 的三个训练种子和 Flat-PPO 的一个训练种子，每个组合每工况两班。排查使用冻结 checkpoint、既有 RPC 数据和收集回执。

| 验证项 | 结果 |
| --- | --- |
| 历史来源与轨迹 | 通过 2,800 个班次的历史登记与回执核对。小批回放完成 16 班和 2,940 个实测决策，其中 BG128 2,220 个、Flat-PPO 720 个。 |
| 数据格式 | 跑通历史 Parquet、JSONL 导入与 NPZ 写回。三个 BG128 checkpoint 的 Actor 和 Critic 均完成推理。 |
| 反事实探针 | 三项各使用 9 个快照并生成合计 78 个曲线点。验证样本覆盖正常与品位临界状态，拥堵分层缺失在结果中标明。 |
| 线性探针 | 跑通真实 UMAP 和 Ridge。测试队列标签恒定时对应 (R^2) 留空，RMSE 保留。 |
| 配对分歧和案例 | 历史验证样本缺少 Greedy / RHO 对照班。用独立合成记录验证了分歧后的 +45 min 对齐、案例匹配、卸载事件连接和候选分支字段读取。 |
| 出图 | Fig. 1–6 均通过 PDF 和 300 dpi PNG 文件检查。历史样本缺失的图面板显示缺口。 |
| PPO 核心 | `python/episode_budget_ppo.py` 前后 SHA256 一致，为 `8e4cfa31c622f5e33756e304eea3f7526547db72ae93f7d9f00808845d61ef96`。 |

此批为脚本验证。论文中的配对结论还需要完成真实 Greedy / RHO 同槽轨迹分析。
